# Solidity-Polkavm

A Solidity smart contract project for Polkadot's Polkavm environment.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file:
```
PRIVATE_KEY=your_private_key
```

## Commands

Compile contracts:
```bash
npm run compile
```

Deploy to Westend Asset Hub:
```bash
npm run deploy
```
